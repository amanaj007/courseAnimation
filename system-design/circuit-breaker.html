Circuit Breaker

Resilience pattern · Closed → Open → Half-Open · Prevents cascade failures

🟢 Closed

Normal operation. All requests pass through. Monitors failures.

🔴 Open

Too many failures. All requests rejected immediately. Waits for timeout.

🟡 Half-Open

Testing recovery. Allows limited requests. Success → Closed, Fail → Open.
